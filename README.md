# simple-note

Simplenote Console prototype in Java. Open Main.java in IntelliJ IDEA, select an installed JDK (8 or newer), and run Main.main(). On Windows you can also use run.bat.

Features: add/view/edit notes, Undo/Redo, Trie prefix search, Inverted Index AND search. Notes are stored in memory only and reset after exit. This is an educational prototype, not Simplenote's internal implementation.
